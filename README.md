# anthologia-continuous-gestures

ANTHOLOGIA — CONTINUOUS GESTURES. 인간의 몸과 춤을 암시하는 선들이 실시간으로 움직이는 웹 기반 생성 작품입니다.
작품 설계와 단계별 범위는 [PROJECT_BRIEF.md](PROJECT_BRIEF.md)에 있습니다.

**현재 상태: 단계 B — 선의 표현 검증 중(Flow).** 단계 A의 안무 A-2와 보이지 않는 신체 구조는 그대로 둡니다.
첫 Flow(천 모델: 몸에 걸리는 면)는 옷으로 읽혀 방향이 철회되었고, 비교용으로 보존되어 아직 기본 감상 화면에 쓰입니다.
새 방향은 별도의 실험으로 개발 화면에서 검토합니다. **Flow 실험 E1**(선들의 흐름 속에서 몸과 춤의 방향이 잠시 나타났다 풀리는 장면)과,
새 핵심 레퍼런스를 따른 **Flow 실험 E2 · 선의 장**(넓은 선의 장 아래에서 몸이 선을 솟게 하는 표현, 지금은 고정 자세의 정지 화면)입니다.
기존 Flow를 대체할지는 시각 검토 뒤에 결정합니다.
단계 A의 뼈대 표현은 **Structure** 모드로 보존해 개발 화면에서 볼 수 있습니다.
형상 전환(단계 C), 포인터·음향·감상용 조작부·모드 선택 UI(단계 D), Trace 모드, 배포(단계 E)는 아직 구현하지 않았습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 시간·보간·신체 제약·Flow·Flow 실험 E1·E2 기하 테스트
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 확인 (http://localhost:4173)
```

## 기본 감상 화면

`http://localhost:5173/`을 열면 바로 움직임이 시작됩니다. 화면에는 캔버스 하나만 있고 버튼이나 설명은 없습니다.
안무 A-2 전체 순서(무게 옮기기 7.2초 → 펼치기 9초 → 방향 바꾸기 9.5초, 25.7초 주기)를 Flow 기본 표현으로 보여 줍니다.
배속은 1입니다(`CONFIG.playback.speed`). 이전 화면(Structure)으로 돌아가려면 `CONFIG.viewing.mode`를 `'structure'`로 바꿉니다.

> 기본 감상 화면은 아직 천 모델 Flow입니다(방향 철회, 비교용 보존). Flow 실험 E1·E2는 개발 화면(`?dev&mode=flow-e1`, `?dev&mode=flow-e2`)에서만 볼 수 있습니다.

## 감상 모드(최종 구성)

최종 작품은 같은 안무를 세 감상 모드로 보여 줄 예정입니다. 세 모드는 같은 안무 시간과 같은 몸 상태를 공유하며,
모드는 그리기만 담당하고 상태를 갖지 않으므로 전환해도 동작이 초기화되지 않습니다.

| 모드 | 내용 | 현재 |
|---|---|---|
| Structure | 최소한의 선으로 몸과 안무를 드러냄(단계 A의 구조선 7개) | 구현됨, 개발 화면에서 선택 |
| Flow | 여러 선이 함께 흐르며 몸을 암시. **기본 감상 모드** | 천 모델(철회, 비교용)과 실험 E1을 비교 중 |
| Trace | 지나간 움직임의 궤적과 시간의 층 | 아직 구현하지 않음 |

관객용 모드 선택 UI는 아직 없습니다(단계 D).

## Flow 실험 E2 · 흐름 (이번 작업: 몸 고정, 선과 경계만 흐름)

E2의 기본 방향은 그대로 두고, 정지 화면의 세 가지를 한 차례 조정한 뒤 **몸은 고정한 채 선의 물결과 바깥 경계만 흐르는 10초 순환**을 만들었습니다.
정지 E2(`mode=flow-e2`)는 비교용으로 그대로 있습니다. 설정은 `CONFIG.flowE2m`입니다.

```
http://localhost:5173/?dev&mode=flow-e2m&panel=0     재생(10초 반복, 시작 배속 ×1.5)
http://localhost:5173/?dev&mode=flow-e2m&speed=1     배속 1로 재생
http://localhost:5173/?dev&mode=flow-e2m&t=0&paused  조정된 정지 화면(흐름 0초)
http://localhost:5173/?dev&mode=flow-e2&panel=0      이전 정지 E2(비교용)
```

검토 질문: **몸이 멈춰 있어도, 선의 물결이 그 위를 지나가는 것으로 느껴지는가?**

**정지 화면의 세 가지 조정**

1. 주변 선을 옅게: 먼 곳의 진하기 0.2 → 0.085. 몸 위는 그대로(0.8). 근접도는 넓게 흐린 값이라 몸의 경계에서 갑자기 바뀌지 않습니다.
2. 좁은 능선 완화: 단면을 둥근 막대의 앞면(윤곽에서 가파름)에서 더 완만하게 올라왔다 내려가는 곡면으로(`relief.profile` 0.5 → 0.7), 장력 3.0 → 2.4, 부드럽게 0.012 → 0.016. 간격에 따른 진함을 줄여(최대 1.7 → 1.35) 솟은 면 윗가장자리에 선이 몰려 외곽선처럼 보이는 것을 줄였습니다. 높이는 늘리지 않았습니다.
3. 가장자리: 옅어지는 길이를 v를 따라 완만하게 바꿔(`edge.fadeVary`) 일부 구간은 옅은 선 끝이 읽히고(`tone.hem`으로 끝 가까이를 조금 진하게), 다른 구간은 흐릿하게 사라집니다. 선마다의 끝 차이는 줄여(0.018 → 0.005) 술 장식처럼 흩어지지 않고 이웃한 끝이 함께 넓은 물결을 이룹니다.

**흐름**

- 장을 이루는 모든 물결이 10초 동안 정수 번 선을 따라 왼쪽에서 오른쪽으로 지나갑니다(끊김 없는 순환). 장의 모양(위치·범위)은 그대로이고 물결만 지나갑니다. 가장 긴 물결도 장을 정확히 한 번 가로지르게 해서 장 전체가 오르내리지 않게 했습니다.
- 선이 지나는 자리마다 같은 막 높이(몸의 굴곡)와 농도를 다시 읽습니다. 그래서 물결이 몸 위를 지날 때 그 자리의 굴곡이 그 물결의 모양으로 바뀝니다. 몸의 굴곡만 따로 출렁이는 것이 아닙니다.
- 바깥쪽(선의 양 끝 가까이)과 경계의 물결은 같은 흐름을 0.6초 늦게, 조금 크게 따릅니다. 따로 진동하지 않습니다.
- 투명도를 시간에 따라 바꾸지 않습니다. 밝은 점·점선 장식은 없습니다.
- 몸과 막 높이는 한 번만 계산하고, 선은 프레임마다 다시 계산합니다(흐름 시간의 순수 함수).

**검증과 한계**

- `tests/veil-flow.test.ts`: 몸·막 높이가 시간과 무관, 주기 끝과 시작이 이어짐, 1/60초 사이 점의 평균 이동 < 0.004, 장의 평균 위치 변화가 점들의 이동보다 훨씬 작음(통째로 이동하지 않음), 같은 선이 몸 위에서 받는 솟음이 시간마다 다름, 바깥쪽의 지연. 모두 통과했으며 기능 검증일 뿐입니다.
- 검토 영상은 헤드리스 Chromium에서 1/24초 간격으로 정지시켜 캡처(1152×768)한 프레임을 이은 것입니다. **연속 재생을 직접 보지 못했습니다.** 물결이 '몸 위를 지나간다'고 느껴지는지는 판단하지 않았습니다.
- 정지 프레임에서 본 것: 몸은 같은 자리에 있고 몸 위의 선 배치와 바깥 경계가 시간마다 달라집니다. 장의 바깥 모양이 어떤 순간에는 사각형에 가깝게 보입니다. 몸의 조형(허리·다리 아래)은 여전히 약합니다.

## Flow 실험 E2 · 선의 장 (이전 작업, 정지 화면)

새 핵심 레퍼런스(넓은 선의 장 아래에서 몸이 선을 솟게 하는 드로잉)를 따른 별도 실험입니다. **고정 자세 하나의 정지 화면**이며 움직임은 아직 없습니다.

```
http://localhost:5173/?dev&mode=flow-e2&panel=0      검토 화면(선만)
http://localhost:5173/?dev&mode=flow-e2               개발 패널과 함께
http://localhost:5173/?dev&mode=flow-e2&refs=1       선을 솟게 한 자세의 관절을 파란 선으로 겹쳐 보기(개발용)
```

레퍼런스와 비슷한 비율로 보려면 브라우저 창을 가로로 넓게(약 3:2) 둡니다. 개발 패널의 표현 선택이나 `M`으로도 E2로 갈 수 있습니다.

**레퍼런스에서 읽은 구조**

- 흰 바탕 위에 거의 수평으로 조금 오른쪽이 올라가는 가는 선 약 90개가 화면 너비 대부분을 채운 하나의 장을 이룹니다.
  장은 크게 물결치는 깃발 같은 모양이고, 위·아래 가장자리는 맨 끝 선 자체가, 좌우 가장자리는 선마다 조금씩 다른 끝이 만듭니다.
- 몸은 장 아래에 있습니다. 같은 선이 주변에서 들어와 몸 위에서 솟고 휘었다가 다시 주변으로 나갑니다. 선이 몸에서 끝나지 않습니다.
- 머리 위의 선은 위로 둥글게 휘고(∩), 굴곡의 윗가장자리에서는 선이 모이며 솟은 면 뒤로 숨습니다. 아래쪽 비탈에서는 간격이 벌어집니다.
- 몸 위의 선은 진하고 선명하며, 멀어질수록 옅어집니다. 회색 면 음영(머리 아래, 허리, 엉덩이)이 부피를 크게 돕습니다(이번 구현에서는 쓰지 않음).
- 몸은 대각선으로 기울어 있고 장이 침대 시트처럼 보여 누운 몸으로도 읽힐 수 있습니다.

**구현(책임별 모듈)**

| 책임 | 파일 | 내용 |
|---|---|---|
| 몸의 자세 | `motion/still.ts` | 고정 자세 하나를 기존 몸 계산(발 고정, 다리 길이, 팔)에 통과시킴. 오른 다리로 서고 왼 다리는 접어 듦, 왼팔은 위·오른팔은 옆(정면에서 오른팔이 화면 왼쪽) |
| 몸의 입체적 영향 | `form/veil-relief.ts` | 가늘어지는 둥근 막대(가는 목, 넓은 가슴, 허리, 골반, 팔다리)의 정면 단면 높이 → 막의 장력(기울기 한도)으로 윤곽에서 완만히 내려감 → 부드럽게. 근접도와 농도용 기울기도 여기서 |
| 넓은 선의 장과 흐름 | `form/veil-sheet.ts` | (u, v) 막 위의 선 100개. 몇 개의 긴 물결의 합을 모든 선이 공유. 가장자리의 끝 위치는 v의 완만한 물결 + 선마다 작은 차이. 몸과 무관 |
| 몸에 의한 국소 굴곡 | `form/veil.ts` | 막의 높이만큼 선을 화면 위로 밀어 솟게 함(무대 위의 몸을 조금 아래에서 보는 시점). 솟은 면 뒤로 가는 선은 숨은 선 제거로 감춤 |
| 농도와 가장자리 | `form/veil-tone.ts` | 근접도(먼 곳 옅게, 몸 위 중간 회색) × 선 간격(모이면 조금 진하게, 선을 따라 평균) × 빛을 등진 비탈(조금 진하게) × 선 끝과 장의 위·아래에서 서서히 사라짐 |
| 시간과 렌더링 | `render/veil.ts`, `render/modes.ts` | 진하기를 40단계로 나눠 같은 단계의 선분을 한 경로로 그림. 지금은 시간과 무관한 정지 화면이라 기하를 한 번 계산해 재사용 |

면 채우기, 외곽선, 뼈대, 이미지 배경이나 왜곡은 쓰지 않습니다. 화면의 모든 선은 위 과정으로 계산해 그린 선입니다.

**레퍼런스와 구현의 차이(같은 크기로 나란히 놓고 본 것)**

- **세워진 방향:** 구현은 머리가 위, 골반이 그 아래, 지지 다리가 아래로 수직으로 이어집니다. 레퍼런스보다 세워진 몸이 분명하다고 봅니다. 다만 선이 위로 솟는 방식 때문에 굴곡이 산등성이처럼 읽히는 순간이 있습니다.
- **몸의 조형:** 레퍼런스는 잘록한 허리, 가슴과 엉덩이의 곡선, 비틀린 몸통이 조각처럼 또렷합니다. 구현은 머리·목·어깨·옆으로 뻗은 팔·몸통·접은 다리가 읽히지만 덩어리가 더 단순하고 둥글습니다. 허리와 엉덩이의 곡선, 지지 다리의 아랫부분(정강이·발)은 약하고, 위로 든 팔은 가는 능선으로만 보입니다.
- **음영:** 레퍼런스의 부피감 상당 부분은 회색 면 음영에서 옵니다. 구현은 선의 휨·간격·진하기로만 부피를 만들어 같은 자리에서 더 평평하게 보입니다.
- **선의 장:** 레퍼런스의 장은 더 크게 물결치는 깃발 모양이고 선의 방향이 더 기울어 있습니다. 구현의 장은 물결이 작고 둥근 사각형에 가깝습니다. 선 간격(1536×1024에서 약 9px)은 레퍼런스와 비슷하게 맞췄습니다.
- **몸과 주변의 연결:** 레퍼런스에서는 위로 든 팔의 능선이 장의 모서리까지 크게 휘어 나가며 주변의 흐름이 몸에 반응합니다. 구현은 몸에서 조금만 떨어져도 선이 거의 휘지 않습니다.
- **솟은 면의 윗가장자리:** 머리 위와 어깨선에서는 선이 모였다가 숨어서 짙은 선 하나처럼 보입니다. 레퍼런스에도 있는 현상이지만, 구현에서는 외곽선처럼 읽힐 여지가 있습니다.
- **가장자리:** 선의 끝이 선마다 다르게 끝나 물결 경계를 이룹니다. 왼쪽 아래는 선 끝이 조금 거칠게 흩어져 보입니다.

## Flow 실험 E1 (이전 작업)

목표: **선들이 서로 연관되어 유동적으로 흐르다가 잠시 몸과 춤의 방향을 암시하고, 다시 다른 흐름으로 풀리는 하나의 짧은 장면.**
천 모델의 수치를 바꾼 것이 아니라 별도의 기하(`src/form/stream.ts`, 설정 `CONFIG.flowE1`)입니다.

**장면.** A-2 전체 순서의 5.6초부터 19초(무게 옮기기 회복 → 펼치기 → 방향 바꾸기의 준비·회전 앞부분)를 장면 시간 0–19초로 반복합니다.

| 장면 시간 | 내용 |
|---|---|
| 0–3.3 | 흐름만: 네 개의 띠가 하나의 닫힌 경로를 시간차를 두고 따라 하나로 엮인 흐름처럼 움직임 |
| 3.3–9.4 | 팔의 확장: 두 띠가 팔이 뻗는 방향을 따라 바깥으로 나갔다 돌아오는 긴 고리로 바뀜(펼치기) |
| 7.0–15 | 몸통·골반의 비틀림: 두 띠가 가슴·골반 높이에서 몸의 축을 돌며, 어깨선과 골반선의 각도 차만큼 말림 |
| 13–19 | 풀림과 여운: 목표가 다시 공통 흐름으로 돌아가고, 띠에는 직전 움직임의 방향과 모양이 남아 흘러 나감 |

**구성.**

- 띠 4개. 각 띠는 공간을 움직이는 '머리'가 끌고 가는 인접한 가는 선 22개입니다. 띠는 머리가 지나온 자리(약 2.5초)입니다.
- **모임·펼침·비틀림.** 띠의 폭과 말림 각은 머리가 지나간 순간의 값이 띠를 따라 함께 흘러갑니다. 머리가 느리면 결이 모이고, 빠르면 벌어지며, 말림 각이 바뀌면 띠가 뒤집혀 결이 서로 넘어갑니다(뒤집힌 안쪽은 옅게).
- 선마다 따로 흔들리는 무작위는 없고, 고정된 모양 전체를 흔드는 변형장도 쓰지 않습니다.
- **몸의 방향은 일시적인 목표**입니다. 몸의 영향(띠마다 나타남·풀림 시각)이 있는 동안만 머리의 목표가 공통 흐름의 경로에서 몸에서 얻은 경로로 옮겨 갑니다. 관절은 지나야 하는 고정점이 아니며, 어깨 끝·허리·매듭·소매·자락 같은 고정 구조는 없습니다. 몸의 외곽이나 뼈대는 그리지 않습니다.
- **풀림.** 영향이 줄면 목표가 흐름 경로로 돌아가므로 경로·간격·방향이 함께 바뀝니다. 투명도는 바꾸지 않습니다.
- **여운.** 머리는 목표를 2차 감쇠 응답(천 모델과 같은 관성 함수, 주기 0.8초, 감쇠 0.5)으로 따르므로 이전 방향으로 조금 더 갔다가 돌아옵니다.
- 모든 값은 장면 시간의 순수 함수입니다. 과거 머리 위치는 다시 계산하며(1/30초 격자, 격자 사이 보간), 시간 탐색·정지·반복이 같은 장면을 만듭니다.

**보기.**

```
/?dev&mode=flow-e1                       E1 장면(0–19초 반복)
/?dev&mode=flow-e1&presence=0            작업 순서 1의 확인: 몸의 영향 없이 흐름만
/?dev&mode=flow-e1&t=6.3&paused&panel=0  팔의 확장 장면에서 정지
/?dev&compare=modes                      Structure · Flow(천 모델) · E1 나란히 (같은 시계)
```

개발 패널의 표현 선택 상자 또는 `M`으로 Structure → Flow(천 모델) → Flow 실험 E1을 오갑니다. `B` 또는 'E1 몸 영향' 체크 상자로 몸의 영향을 끄고 켭니다.
E1만 볼 때 `t`는 장면 시작으로부터의 초입니다.

## Flow 표현 (천 모델 — 방향 철회, 비교용 보존)

아래는 첫 Flow 시도입니다. 앞쪽 두 스카프·뒤쪽 자락·가슴의 X자 매듭 구조 때문에 옷으로 읽혀 '천 모델', '몸에 걸리는 면', '실루엣을 드러내는 가림'의 방향은 철회되었습니다.
비교를 위해 코드와 수치를 그대로 두었습니다.

레퍼런스 이미지(가느다란 선들이 띠·면을 이루며 접히고 펼쳐지는 드로잉)를 선의 밀도·간격·접힘·곡률의 기준으로 삼았습니다.
외곽 형태를 복제하지 않습니다.

- **천처럼 흐르는 면.** 폭이 넓은 긴 면(스카프·자락) 세 장이 몸에 걸립니다.
  - 앞쪽 두 면: 들어 올린 팔 → 어깨 → 가슴을 가로질러 → 반대쪽 골반을 감고 → 뒤로 끌리는 끝. 두 면이 가슴 위에서 X로 엇갈려 매듭을 만듭니다.
  - 뒤쪽 면: 목 뒤에서 등을 타고 뒤로 넓게 흐르는 자락.
- **선은 면의 길이 방향 결**입니다. 사지마다 붙인 튜브나 몸의 외곽선이 아닙니다.
- **몸은 선들 사이에서 드러납니다.** 보이지 않는 몸의 부피(캡슐을 매끄럽게 이은 표면)에 면이 걸리고 밀려나서, 어깨·팔·가슴을 넘을 때 결이 휘고 촘촘해집니다. 면 사이로는 옆구리·다리·머리가 비치고, 보이지 않는 몸이 뒤의 결을 가려 빈 공간으로 드러납니다. 모든 부위가 항상 선명하지는 않습니다.
- **간격.** 면이 비틀리거나 몸의 곡면에서 돌아서면 결이 모이고(긴장), 펼쳐지면 벌어집니다(부피). 응축할수록 결과 나란한 주름이 깊어집니다.
- **관성.** 걸린 곳(어깨·팔·골반)은 몸을 빠르게 따르고, 자유로운 끝은 2차 감쇠계의 응답으로 따라옵니다. 몸이 멈추거나 방향을 바꾸면 끝자락은 이전 방향으로 조금 더 갔다가 돌아옵니다. 반복 파동이 아니라 실제 몸의 움직임에 대한 응답이며, 과거 몸 상태를 다시 계산해서 쓰므로 시간 탐색과 재현이 그대로 유지됩니다.
- **앞뒤와 가림.** 천을 작은 조각으로 나눠 먼 것부터 그리고, 각 조각은 배경색으로 뒤를 덮은 뒤 자기 결을 그립니다. 앞의 천이 뒤의 결을 가리고, 보이지 않는 몸도 뒤의 결을 가립니다. 접혀서 안쪽 면을 보이는 곳은 옅게 그립니다. 외곽선이나 채운 면은 그리지 않습니다.
- 선마다 따로 흔들리는 무작위는 없습니다. 아주 약한 공유 변형장만 자유로운 부분에 더합니다.

**세 설정.** 개발 화면에서 같은 동작·같은 시점을 비교할 수 있습니다.

| 설정 | 내용 | 상태 |
|---|---|---|
| Flow 1 · 몸이 읽힘 | 기본 표현에서 천이 몸에 더 붙고 덜 늘어짐 | 미조정(기본 표현의 수치만 바꾼 변형) |
| Flow 2 · 경계 | 몸과 추상의 경계. **기본 표현** | 검토 구간 기준으로 다듬는 중 |
| Flow 3 · 흐름 | 천이 더 늘어지고 넓게 흐르며 몸이 희미함 | 미조정(기본 표현의 수치만 바꾼 변형) |

## 개발용 검토 화면

주소에 `?dev`를 붙이면 열립니다(예: `http://localhost:5173/?dev`). 기본 감상 화면에서는 이 패널의 코드도 불러오지 않습니다.
개발 화면은 **검토 구간 '펼침 → 방향 전환 → 멈춤'**(A-2 전체 순서의 9.0~22.8초 반복), Flow 2, 배속 ×1.5로 시작합니다.

| 기능 | 조작 |
|---|---|
| 구절 선택 | 선택 상자, 또는 `0` 전체 순서 · `1` 무게 옮기기 · `2` 펼치기 · `3` 방향 바꾸기 · `4` 검토 구간 |
| 표현(감상 모드) | 선택 상자 또는 `M`: Structure → Flow(천 모델) → Flow 실험 E1 → E2 · 선의 장 → E2 · 흐름. 시간은 그대로 이어집니다(E2는 정지 화면) |
| E1 몸 영향 | 체크 상자 또는 `B` (끄면 몸 없이 흐름만) |
| Flow 설정 | 선택 상자 또는 `F`: 1 → 2 → 3 |
| 나란히 비교 | 선택 상자 또는 `C`: 없음 → Flow 1·2·3 → Structure·Flow·E1 → 안무 A-1·A-2 |
| 안무 버전 | 선택 상자 또는 `V`: A-2 현재 ↔ A-1 이전. 바꾸면 그 구절의 처음으로 돌아갑니다 |
| 정지 / 재생 | `Space` 또는 재생 버튼 |
| 시간 탐색 | 슬라이더, `←` `→` 1/30초, `Shift` + `←` `→` 1초 (이동하면 자동으로 정지) |
| 속도 | ×0.25 · ×0.5 · ×1 · ×1.25 · ×1.5 · ×2 (시작값 ×1.5) |
| 기준점 표시 | 체크 상자 또는 `R` (관절 점·하중 등 개발용 표시. 감상 모드와 별개로 위에 겹쳐 그림, 기본은 꺼짐) |

비교 화면의 칸들은 같은 시계와 같은 몸 상태를 씁니다. 표현·Flow 설정·비교 화면을 바꿔도 시간은 이어지고,
구절이나 안무 버전을 바꾸면 그 구절(검토 구간이면 구간)의 처음으로 돌아갑니다.

기준점 표시에서 보이는 것:

- 파란 점: 머리, 목, 가슴, 허리, 골반, 어깨, 팔꿈치, 손목, 고관절, 무릎, 발목
- 발밑의 붉은 원: 하중의 크기. 하중이 60% 이상이면 진하게 채워져 지지 발로 표시됩니다. 점선은 발목이 바닥에서 들린 높이입니다.
- 초록 점과 십자: 무게 중심과 그 바닥 투영
- 골반 아래의 짧은 파란 선: 골반이 향한 방향
- 패널 아래쪽: 안무 버전, 현재 구절·부분(준비/진행/유예/회복), 좌우 하중 비율. 다리가 닿지 않아 골반을 내려야 했으면 `골반 보정` 값이 함께 나타납니다(안무 데이터 오류의 신호).

특정 시점을 주소로 공유할 수 있습니다.

```
/?dev&t=3.0&paused                         검토 구간 시작에서 3초 뒤(펼친 팔)에서 정지
/?dev&compare=presets&t=10.2&paused        회전 중 Flow 1·2·3 나란히
/?dev&compare=modes                        Structure와 Flow 나란히
/?dev&phrase=all&mode=structure            단계 A의 화면(전체 순서, Structure)
/?dev&t=0.9&paused&panel=0                 패널 없이 선만 보기(캡처용)
```

`phrase`는 `scene | all | shift | open | turn`(기본 `scene`), `mode`는 `structure | flow | flow-e1 | flow-e2 | flow-e2m`, `presence=0`은 E1의 몸 영향 끔, `preset`은 `1 | 2 | 3`,
`compare`는 `presets | modes | versions`(값 없이 쓰면 `versions`), `v`는 `a1 | a2`,
`t`는 초(검토 구간에서는 구간 시작으로부터의 초), `paused`는 정지 상태로 시작, `speed`는 배속(목록의 값),
`refs=1`은 기준점 표시, `panel=0`은 패널 숨김입니다. 같은 안무·`phrase`·`t`·표현은 항상 같은 장면을 만듭니다.

### 움직임을 만드는 방식

- **작품 시간 → 자세는 순수 함수**입니다. 누적 시뮬레이션이 없으므로 시간 탐색, 정지 후 재생, 반복 재생이 항상 같은 장면을 만듭니다. Flow의 관성도 과거 시점의 몸을 다시 계산해 쓰므로 이 성질을 유지합니다.
- 각 구절은 28개 자세 채널(골반 위치·기울기, 가슴의 방향·기울기·굽힘, 머리, 팔 각도, 발 위치·들림)의 키프레임입니다. 키 사이는 단조 3차 보간으로 이어지고, 같은 값을 두 번 두면 정지, 극값에서는 감속이 됩니다. 준비 동작은 반대 방향의 작은 키로 직접 적었습니다.
- 모든 구절의 키는 채널마다 하나의 순환 곡선에 모입니다. A-1은 구절마다 t = 0에 휴식 자세 키를 두었고(`anchorRest`), A-2는 경계에 고정 자세가 없어 앞 구절의 마지막 키에서 다음 구절의 첫 키로 곧바로 이어집니다. 그래서 경계에서도 위치와 속도가 연속입니다.
- **골반과 가슴이 움직임을 이끕니다.** 머리, 위팔, 아래팔, 손끝은 각각 0.16 / 0.10 / 0.22 / 0.36초 이전 시점의 몸통·팔 자세에서 방향을 가져옵니다. 위치는 현재 부모 관절에서 이어지므로 길이는 그대로이고, 말단만 늦게 따라옵니다.
- **지지 발은 고정됩니다.** 발 위치는 안무 데이터에서 하중이 없을 때만 바뀌고, 다리는 역기구학으로 풀며, 다리가 닿지 않으면 발을 끌어오는 대신 골반을 낮춥니다.
- 하중은 무게 중심의 바닥 투영을 두 발 사이에 놓아 계산하고, 바닥에서 들린 발은 하중을 받지 않습니다.
- 회전 채널은 한 바퀴씩 누적되므로 방향 바꾸기 뒤에도 역회전 없이 다음 구절로 이어집니다.
- 정지 구간에서도 몸이 굳지 않도록 아주 작은 호흡이 있습니다. 호흡 주기는 순서 길이의 약수로 맞췄습니다.

### 시점

정면에서는 무릎 굽힘, 몸통의 말림·젖힘, 회전 준비가 화면 깊이 방향으로 사라졌습니다. 그래서 몸을 약 24° 돌린 3/4 시점에서 약간 내려다보도록 했습니다(`CONFIG.camera`). 이 시점 역시 검토할 가설입니다.

## 남은 한계

- 안무는 임시안이며, 좌우·크기·길이의 변주가 없는 고정 순서입니다.
- A-2는 순서(무게 옮기기 → 펼치기 → 방향 바꾸기)를 전제로 각 구절의 끝과 시작을 맞췄습니다. 구절 하나만 반복하면 그 구절의 끝이 자기 시작으로 이어지므로 경계의 흐름이 전체 순서보다 덜 자연스러울 수 있습니다.
- 감상 화면의 배속은 1로 두었습니다. 검토 후 정한 배속을 `CONFIG.playback.speed`에 반영하면 됩니다.
- E2는 고정 자세 하나의 정지 화면입니다. 시간, 안무, 흐름의 움직임은 아직 연결하지 않았습니다. 움직임 단계에서는 막 높이 계산(지금 Node에서 약 0.2초)을 매 프레임에 맞게 줄여야 합니다.
- E2의 몸 부피(가늘어지는 둥근 막대)는 근사입니다. 허리·가슴·엉덩이의 곡선이 레퍼런스보다 단순합니다. 숨은 선 판정은 화면 세로 방향만 고려합니다.
- E1은 기본 표현 하나뿐인 실험입니다. 장면은 A-2의 5.6–24.6초 한 구간이며, 장면 전후는 이어 붙이지 않고 장면 안에서 반복합니다. 기본 감상 화면에는 아직 쓰지 않습니다.
- E1의 몸 경로(팔 방향의 고리, 몸축을 도는 궤도)와 나타남·풀림 시각은 가설입니다. 몸의 영향 구간은 안무 시각에 손으로 맞췄고, 안무에서 자동으로 얻지 않습니다.
- E1의 선은 앞뒤 가림이 없고, 띠가 뒤집힌 곳을 옅게 그리는 것만으로 앞뒤를 나눕니다. 겹치는 곳에서 선이 비쳐 보입니다.
- 천 모델 Flow는 방향이 철회되어 더 다듬지 않았습니다. 무게 옮기기·응축 장면, Flow 1·3 변형도 다듬지 않은 상태입니다.
- Flow의 몸 부피는 캡슐을 이은 근사라서, 천이 머리나 팔을 지날 때 둥근 모양이 드러나는 순간이 있습니다.
- 가림은 천을 작은 조각 단위로 깊이 정렬하는 근사입니다. 거의 같은 깊이에서 겹치는 곳은 조각 경계를 따라 계단처럼 끊길 수 있습니다.
- Flow 세 칸 비교 화면은 프레임이 느립니다(개발용). 감상 화면은 한 칸입니다.
- 발은 발목 점 하나로만 다루므로 발 앞꿈치·뒤꿈치의 구분이나 회전 중 발의 비틀림은 표현하지 않습니다.
- 말단 시간차는 이전 시점의 자세를 빌려오는 방식이라, 빠른 회전에서 팔꿈치·손끝이 제약에 걸려 각이 지는 순간이 있을 수 있습니다.
- 무게 중심은 골반·가슴·머리만으로 계산한 근사입니다.
- 화면 크기 변경 시 비례를 다시 계산하지만, 감상 환경(움직임 감소 설정, 터치, 탭 복귀 처리의 완성)은 단계 D의 범위입니다. 탭이 가려지면 프레임이 멈추고, 돌아왔을 때 공백 시간을 반영하지 않는 것까지만 되어 있습니다.
