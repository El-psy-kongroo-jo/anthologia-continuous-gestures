# anthologia-continuous-gestures

ANTHOLOGIA — CONTINUOUS GESTURES. 인간의 몸과 춤을 암시하는 선들이 실시간으로 움직이는 웹 기반 생성 작품입니다.
작품 설계와 단계별 범위는 [PROJECT_BRIEF.md](PROJECT_BRIEF.md)에 있습니다.

**현재 상태: 단계 A — 움직임 검증.** 몸 하나가 세 안무 구절을 최소한의 구조선 7개로 보여 줍니다.
선의 표현(단계 B), 형상 전환(단계 C), 포인터·음향·감상용 조작부(단계 D), 배포(단계 E)는 아직 구현하지 않았습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 시간·보간·신체 제약 테스트
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 확인 (http://localhost:4173)
```

## 기본 감상 화면

`http://localhost:5173/`을 열면 바로 움직임이 시작됩니다. 화면에는 캔버스 하나만 있고 버튼이나 설명은 없습니다.
세 구절(무게 옮기기 10초 → 펼치기 11초 → 방향 바꾸기 13초)이 34초 주기로 반복됩니다.

## 개발용 검토 화면

주소에 `?dev`를 붙이면 열립니다(예: `http://localhost:5173/?dev`). 기본 감상 화면에서는 이 패널의 코드도 불러오지 않습니다.

| 기능 | 조작 |
|---|---|
| 구절 선택 | 선택 상자, 또는 `0` 전체 순서 · `1` 무게 옮기기 · `2` 펼치기 · `3` 방향 바꾸기 |
| 정지 / 재생 | `Space` 또는 재생 버튼 |
| 시간 탐색 | 슬라이더, `←` `→` 1/30초, `Shift` + `←` `→` 1초 (이동하면 자동으로 정지) |
| 속도 | ×0.25 · ×0.5 · ×1 |
| 기준점 표시 | 체크 상자 또는 `R` |

기준점 표시에서 보이는 것:

- 파란 점: 머리, 목, 가슴, 허리, 골반, 어깨, 팔꿈치, 손목, 고관절, 무릎, 발목
- 발밑의 붉은 원: 하중의 크기. 하중이 60% 이상이면 진하게 채워져 지지 발로 표시됩니다. 점선은 발목이 바닥에서 들린 높이입니다.
- 초록 점과 십자: 무게 중심과 그 바닥 투영
- 골반 아래의 짧은 파란 선: 골반이 향한 방향
- 패널 아래쪽: 현재 구절·부분(준비/진행/유예/회복), 좌우 하중 비율. 다리가 닿지 않아 골반을 내려야 했으면 `골반 보정` 값이 함께 나타납니다(안무 데이터 오류의 신호).

특정 시점을 주소로 공유할 수 있습니다.

```
/?dev&phrase=turn&t=5.2&paused       방향 바꾸기 5.2초에서 정지
/?dev&phrase=shift&t=5.8&paused&refs=0&panel=0   기준점과 패널 없이 선만 보기(캡처용)
```

`phrase`는 `all | shift | open | turn`, `t`는 초, `paused`는 정지 상태로 시작, `refs=0`은 기준점 숨김, `panel=0`은 패널 숨김입니다.
같은 `phrase`와 `t`는 항상 같은 장면을 만듭니다.

### 움직임을 만드는 방식

- **작품 시간 → 자세는 순수 함수**입니다. 누적 시뮬레이션이 없으므로 시간 탐색, 정지 후 재생, 반복 재생이 항상 같은 장면을 만듭니다.
- 각 구절은 28개 자세 채널(골반 위치·기울기, 가슴의 방향·기울기·굽힘, 머리, 팔 각도, 발 위치·들림)의 키프레임입니다. 키 사이는 단조 3차 보간으로 이어지고, 같은 값을 두 번 두면 정지, 극값에서는 감속이 됩니다. 준비 동작은 반대 방향의 작은 키로 직접 적었습니다.
- **골반과 가슴이 움직임을 이끕니다.** 머리, 위팔, 아래팔, 손끝은 각각 0.16 / 0.10 / 0.22 / 0.36초 이전 시점의 몸통·팔 자세에서 방향을 가져옵니다. 위치는 현재 부모 관절에서 이어지므로 길이는 그대로이고, 말단만 늦게 따라옵니다.
- **지지 발은 고정됩니다.** 발 위치는 안무 데이터에서 하중이 없을 때만 바뀌고, 다리는 역기구학으로 풀며, 다리가 닿지 않으면 발을 끌어오는 대신 골반을 낮춥니다.
- 하중은 무게 중심의 바닥 투영을 두 발 사이에 놓아 계산하고, 바닥에서 들린 발은 하중을 받지 않습니다.
- 회전 채널은 한 바퀴씩 누적되므로 방향 바꾸기 뒤에도 역회전 없이 다음 구절로 이어집니다.
- 정지 구간에서도 몸이 굳지 않도록 아주 작은 호흡이 있습니다. 호흡 주기는 순서 길이의 약수로 맞췄습니다.

### 시점

정면에서는 무릎 굽힘, 몸통의 말림·젖힘, 회전 준비가 화면 깊이 방향으로 사라졌습니다. 그래서 몸을 약 24° 돌린 3/4 시점에서 약간 내려다보도록 했습니다(`CONFIG.camera`). 몸 뒤쪽의 선은 조금 옅고 가늘게 그립니다. 이 시점 역시 검토할 가설입니다.

## 임시 안무

**기존 Anthologia 동작 자료는 아직 제공되지 않았습니다.** `src/motion/phrases.ts`의 자세와 타이밍은 PROJECT_BRIEF.md 4장의 구절 설명만을 근거로 만든 임시안이며, 기존 작품을 분석한 결과가 아닙니다. 자료가 제공되면 이 파일을 그 자료에 맞춰 다시 씁니다.

| 구절 | 길이 | 준비 | 진행 | 유예 | 회복 |
|---|---|---|---|---|---|
| 무게 옮기기 | 10초 | 0–1.7 왼발에 실리며 무릎을 굽혀 밀어낼 힘을 모음 | 1.7–5.3 골반이 오른발 위로 건너가며 솟고, 몸통은 늦게 반대로 기울어 균형을 잡음. 왼쪽 뒤꿈치가 풀림 | 5.3–6.9 오른발 위에서 머묾 | 6.9–10 뒤꿈치 → 골반 → 몸통 순서로 가운데로 돌아옴 |
| 펼치기 | 11초 | 0–2.8 무릎을 굽히고 몸통을 말며 팔을 앞으로 모음(응축) | 2.8–6.2 가슴이 먼저 열리고 솟은 뒤 위팔 → 아래팔 → 손끝 순서로 대각선으로 펼쳐짐. 무게가 오른발 쪽으로 조금 이동 | 6.2–7.8 조금 더 뻗으며 머묾 | 7.8–11 몸통이 먼저, 팔과 손끝이 늦게 내려앉음 |
| 방향 바꾸기 | 13초 | 0–3.2 오른발로 무게를 옮기고 무릎을 굽히며 반대 방향으로 감음. 왼발을 바깥으로 열어 접어 올림 | 3.2–8.0 어깨가 먼저 출발하고 골반이 약 0.3–0.4초 늦게 따라 한 바퀴 회전. 어깨가 살짝 지나쳤다가 감속하고, 팔은 늦게 열림 | 8.0–9.4 왼발을 내려 딛고 머묾 | 9.4–13 가운데로 돌아오며 팔을 내림 |

이 결과는 기능 검증입니다. 선의 표현이나 안무가 예술적으로 승인되었다는 뜻이 아닙니다.

## 시각 검토 항목

재생(×1)과 느린 재생(×0.25·×0.5)으로 각각 확인해 주세요. 기준점을 켜고 끈 상태를 모두 보는 것이 좋습니다.

**전체**
- [ ] 선의 장식 없이 7개 구조선만으로 무게 이동과 동작의 계기가 보이는가
- [ ] 단순한 좌우 흔들림으로 읽히지 않는가(높낮이, 골반·어깨의 반대 기울기, 자유 다리의 반응)
- [ ] 구절 사이(10초, 21초, 34초→0초)에서 멈춤이나 튐 없이 이어지는가. 사이의 짧은 머묾이 자연스러운가
- [ ] 정지 구간이 죽은 정지처럼 보이지 않는가(호흡의 크기)
- [ ] 3/4 시점이 적절한가, 정면이 나은가(`CONFIG.camera.yaw`)
- [ ] 구절 길이 10/11/13초가 너무 느리거나 빠르지 않은가

**무게 옮기기**
- [ ] 준비(0–1.7초)에서 왼발로 실리는 작은 반대 동작이 '밀어내기 위한 준비'로 읽히는가
- [ ] 오른발이 버티는 동안 발이 미끄러져 보이지 않는가(기준점 표시의 붉은 원 위치)
- [ ] 몸통 기울기가 골반보다 늦게 오는 것이 무게를 받아 내는 반응으로 보이는가
- [ ] 회복에서 뒤꿈치 → 골반 → 몸통 순서가 읽히는가

**펼치기**
- [ ] 응축이 충분히 작아지는가(무릎, 몸통의 말림, 머리)
- [ ] 가슴이 먼저 열리고 팔이 뒤따르는 순서가 보이는가
- [ ] 손끝의 지연이 '말단의 지연'으로 보이는가, 아니면 손목이 꺾인 것처럼 보이는가(`CONFIG.lag.hand`, `maxHandBend`)
- [ ] 펼친 자세가 대칭의 T자처럼 딱딱하지 않은가

**방향 바꾸기**
- [ ] 준비의 감기(반대 방향 회전)와 무릎 굽힘이 보이는가
- [ ] 어깨와 골반의 시차가 보이는가, 한 덩어리로 도는 것처럼 보이지 않는가
- [ ] 회전 중 팔의 끌림이 엉킨 선처럼 보이지 않는가(4.5–6.5초 부근에 팔 선이 겹치거나 말리는 순간이 있음)
- [ ] 접어 올린 왼다리가 회전을 읽게 돕는가, 방해하는가
- [ ] 감속과 착지(7.3–8.6초)에 무게가 느껴지는가

## 남은 한계

- 안무는 임시안이며, 좌우·크기·길이의 변주가 없는 고정 순서입니다.
- 구조선은 관절을 잇는 곡선이며, 단계 B의 선 표현(몸을 가로지르는 곡선, 끊김, 밀도)은 아직 없습니다. 지금은 막대 인형에 가깝게 보일 수 있습니다.
- 발은 발목 점 하나로만 다루므로 발 앞꿈치·뒤꿈치의 구분이나 회전 중 발의 비틀림은 표현하지 않습니다.
- 말단 시간차는 이전 시점의 자세를 빌려오는 방식이라, 빠른 회전에서 팔꿈치·손끝이 제약에 걸려 각이 지는 순간이 있을 수 있습니다.
- 무게 중심은 골반·가슴·머리만으로 계산한 근사입니다.
