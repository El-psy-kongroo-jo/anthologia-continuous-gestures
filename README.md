# anthologia-continuous-gestures

ANTHOLOGIA — CONTINUOUS GESTURES. 인간의 몸과 춤을 암시하는 선들이 실시간으로 움직이는 웹 기반 생성 작품입니다.
작품 설계와 단계별 범위는 [PROJECT_BRIEF.md](PROJECT_BRIEF.md)에 있습니다.

**현재 상태: 단계 A — 움직임 검증(안무 A-2).** 몸 하나가 세 안무 구절을 최소한의 구조선 7개로 보여 줍니다.
첫 검토 뒤 속도와 구절 사이의 연결감을 고친 A-2가 기본이며, 첫 구현 A-1은 개발 화면에서 비교용으로 볼 수 있습니다.
선의 표현(단계 B), 형상 전환(단계 C), 포인터·음향·감상용 조작부(단계 D), 배포(단계 E)는 아직 구현하지 않았습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 시간·보간·신체 제약 테스트
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 확인 (http://localhost:4173)
```

## 기본 감상 화면

`http://localhost:5173/`을 열면 바로 움직임이 시작됩니다. 화면에는 캔버스 하나만 있고 버튼이나 설명은 없습니다.
세 구절(무게 옮기기 7.2초 → 펼치기 9초 → 방향 바꾸기 9.5초)이 휴식 자세로 돌아오지 않고 이어지며 25.7초 주기로 반복됩니다.
감상 화면의 배속은 1입니다(`CONFIG.playback.speed`). 개발 화면은 비교 검토를 위해 1.5배로 시작합니다.

## 개발용 검토 화면

주소에 `?dev`를 붙이면 열립니다(예: `http://localhost:5173/?dev`). 기본 감상 화면에서는 이 패널의 코드도 불러오지 않습니다.

| 기능 | 조작 |
|---|---|
| 구절 선택 | 선택 상자, 또는 `0` 전체 순서 · `1` 무게 옮기기 · `2` 펼치기 · `3` 방향 바꾸기 |
| 정지 / 재생 | `Space` 또는 재생 버튼 |
| 시간 탐색 | 슬라이더, `←` `→` 1/30초, `Shift` + `←` `→` 1초 (이동하면 자동으로 정지) |
| 속도 | ×0.25 · ×0.5 · ×1 · ×1.25 · ×1.5 · ×2 (시작값 ×1.5) |
| 안무 버전 | 선택 상자 또는 `V`: A-2 현재 ↔ A-1 이전. 바꾸면 그 구절의 처음으로 돌아갑니다 |
| 나란히 비교 | 체크 상자 또는 `C`: 왼쪽 A-1, 오른쪽 A-2를 같은 시계로 동시에 재생 |
| 기준점 표시 | 체크 상자 또는 `R` |

**변경 전후 비교.** `C`로 나란히 비교를 켜고 `1`/`2`/`3`으로 구절을 고르면 두 안무가 같은 구절의 처음부터 같은 배속으로 함께 재생됩니다.
A-2가 더 짧으므로 먼저 다음 반복으로 넘어갑니다. 패널에는 각 안무의 시간·구절·부분과 하중이 따로 표시됩니다.

기준점 표시에서 보이는 것:

- 파란 점: 머리, 목, 가슴, 허리, 골반, 어깨, 팔꿈치, 손목, 고관절, 무릎, 발목
- 발밑의 붉은 원: 하중의 크기. 하중이 60% 이상이면 진하게 채워져 지지 발로 표시됩니다. 점선은 발목이 바닥에서 들린 높이입니다.
- 초록 점과 십자: 무게 중심과 그 바닥 투영
- 골반 아래의 짧은 파란 선: 골반이 향한 방향
- 패널 아래쪽: 안무 버전, 현재 구절·부분(준비/진행/유예/회복), 좌우 하중 비율. 다리가 닿지 않아 골반을 내려야 했으면 `골반 보정` 값이 함께 나타납니다(안무 데이터 오류의 신호).

특정 시점을 주소로 공유할 수 있습니다.

```
/?dev&phrase=turn&t=2.8&paused            방향 바꾸기 2.8초에서 정지
/?dev&compare&phrase=open                 펼치기를 A-1·A-2 나란히 비교
/?dev&v=a1&speed=1                        A-1을 배속 1로 보기
/?dev&phrase=shift&t=3.8&paused&refs=0&panel=0   기준점과 패널 없이 선만 보기(캡처용)
```

`phrase`는 `all | shift | open | turn`, `v`는 `a1 | a2`, `compare`는 나란히 비교, `t`는 초, `paused`는 정지 상태로 시작,
`speed`는 배속(목록의 값), `refs=0`은 기준점 숨김, `panel=0`은 패널 숨김입니다. 같은 안무·`phrase`·`t`는 항상 같은 장면을 만듭니다.

### 움직임을 만드는 방식

- **작품 시간 → 자세는 순수 함수**입니다. 누적 시뮬레이션이 없으므로 시간 탐색, 정지 후 재생, 반복 재생이 항상 같은 장면을 만듭니다.
- 각 구절은 28개 자세 채널(골반 위치·기울기, 가슴의 방향·기울기·굽힘, 머리, 팔 각도, 발 위치·들림)의 키프레임입니다. 키 사이는 단조 3차 보간으로 이어지고, 같은 값을 두 번 두면 정지, 극값에서는 감속이 됩니다. 준비 동작은 반대 방향의 작은 키로 직접 적었습니다.
- 모든 구절의 키는 채널마다 하나의 순환 곡선에 모입니다. A-1은 구절마다 t = 0에 휴식 자세 키를 두었고(`anchorRest`), A-2는 경계에 고정 자세가 없어 앞 구절의 마지막 키에서 다음 구절의 첫 키로 곧바로 이어집니다. 그래서 경계에서도 위치와 속도가 연속입니다.
- **골반과 가슴이 움직임을 이끕니다.** 머리, 위팔, 아래팔, 손끝은 각각 0.16 / 0.10 / 0.22 / 0.36초 이전 시점의 몸통·팔 자세에서 방향을 가져옵니다. 위치는 현재 부모 관절에서 이어지므로 길이는 그대로이고, 말단만 늦게 따라옵니다.
- **지지 발은 고정됩니다.** 발 위치는 안무 데이터에서 하중이 없을 때만 바뀌고, 다리는 역기구학으로 풀며, 다리가 닿지 않으면 발을 끌어오는 대신 골반을 낮춥니다.
- 하중은 무게 중심의 바닥 투영을 두 발 사이에 놓아 계산하고, 바닥에서 들린 발은 하중을 받지 않습니다.
- 회전 채널은 한 바퀴씩 누적되므로 방향 바꾸기 뒤에도 역회전 없이 다음 구절로 이어집니다.
- 정지 구간에서도 몸이 굳지 않도록 아주 작은 호흡이 있습니다. 호흡 주기는 순서 길이의 약수로 맞췄습니다.

### 시점

정면에서는 무릎 굽힘, 몸통의 말림·젖힘, 회전 준비가 화면 깊이 방향으로 사라졌습니다. 그래서 몸을 약 24° 돌린 3/4 시점에서 약간 내려다보도록 했습니다(`CONFIG.camera`). 몸 뒤쪽의 선은 조금 옅고 가늘게 그립니다. 이 시점 역시 검토할 가설입니다.

## 임시 안무

**기존 Anthologia 동작 자료는 아직 제공되지 않았습니다.** `src/motion/phrases-a2.ts`(현재)와 `phrases-a1.ts`(이전)의 자세와 타이밍은 PROJECT_BRIEF.md 4장의 구절 설명만을 근거로 만든 임시안이며, 기존 작품을 분석한 결과가 아닙니다. 자료가 제공되면 그 자료에 맞춰 다시 씁니다.

### A-2 (현재)

각 구절의 회복이 다음 구절의 준비가 됩니다. 시간은 구절 안의 초, 괄호는 전체 순서 안의 초(배속 1)입니다.

| 구절 | 준비 | 진행 | 유예 | 회복 → 다음 구절로 |
|---|---|---|---|---|
| 무게 옮기기 7.2초 (0–7.2) | 0–0.7 앞 구절에서 넘어온 왼발 버팀, 짧게 가라앉아 밀어냄 | 0.7–3.3 골반이 오른발 위로 빠르게 건너감. 가슴이 지지 발 쪽으로 돌고 자유로운 왼팔이 열렸다가 늦게 내려앉음. 몸통은 골반보다 늦게 반대로 기울어 균형 | 3.3–4.4 오른발 위에서 머묾 | 4.4–7.2 뒤꿈치를 내리고 가라앉으며 팔이 앞으로 모이기 시작 → 펼치기의 응축 |
| 펼치기 9초 (7.2–16.2) | 0–2.1 더 가라앉고 몸통을 말며 팔을 감쌈. 끝에서 짧게 머묾(눌린 용수철) | 2.1–4.4 가슴이 먼저 튀어 열리고, 위팔 → 아래팔 → 손끝이 약 0.5초 동안 폭발적으로 펼쳐진 뒤 길게 감속 | 4.4–5.6 조금 더 뻗으며 머묾 | 5.6–9 팔이 내려오며 몸이 반대로 감기고 오른발로 실림 → 방향 바꾸기의 준비 |
| 방향 바꾸기 9.5초 (16.2–25.7) | 0–1.3 더 감고 가라앉으며 왼발을 바깥으로 열어 접어 올림 | 1.3–5.2 어깨가 느리게 출발했다가 폭발적으로 돌고, 골반이 약 0.3–0.5초 늦게 따라 한 바퀴. 어깨가 살짝 지나쳤다가 길게 감속, 팔이 늦게 열리고 왼발을 내려 디딤 | 5.2–6.2 머묾 | 6.2–9.5 무게가 왼발로 건너가며 팔이 내려옴 → 무게 옮기기의 버팀 |

### A-1 (이전, 비교용)

무게 옮기기 10초, 펼치기 11초, 방향 바꾸기 13초, 합계 34초입니다. 각 구절이 휴식 자세에서 시작해 휴식 자세로 돌아옵니다. 첫 검토에서 선의 변화량에 비해 느리고, 개별 동작 시범처럼 보인다는 지적을 받았습니다.

### A-1 → A-2 측정 비교

`tests/timing.test.ts`가 아래 개선을 검사합니다. 값은 배속 1 기준이고, '움직임'은 모든 기준점 속도의 제곱평균제곱근(몸 단위/초)입니다. 이 지표는 움직임의 양과 연속성을 잴 뿐, 안무가 좋아졌다는 예술적 판단은 아닙니다.

| 지표 | A-1 | A-2 |
|---|---|---|
| 한 주기 길이 | 34초 | 25.7초 |
| 평균 움직임 | 0.085 | 0.102 |
| 거의 정지(움직임 < 0.03)한 시간 비율 | 32% | 23% |
| 구절 경계 ±0.4초의 최소 움직임 (→무게 옮기기, →펼치기, →방향 바꾸기) | 0.004, 0.002, 0.016 | 0.034, 0.037, 0.048 |
| 준비·회복 중 거의 정지한 비율 (무게 옮기기 / 펼치기 / 방향 바꾸기) | 50% / 10% / 17% | 43% / 10% / 0% |
| 유예 구간의 최소 움직임 (머묾이 남아 있는지) | 0.002 / 0.012 / 0.014 | 0.020 / 0.017 / 0.023 |
| 펼치기 진행: 최대 움직임, 최대/평균, 오름/내림 시간 | 0.17, 1.6, 0.96초/1.89초 | 0.38, 2.4, 0.58초/0.90초 |
| 방향 바꾸기 진행: 최대 움직임, 최대/평균, 오름/내림 시간 | 0.44, 1.6, 2.35초/1.40초 | 0.67, 2.0, 0.97초/1.78초 |
| 시작 후 2.5초 안의 어깨선 방향 변화 / 손끝 이동 | 0.6° / 0.04 | 17.5° / 0.18 |

- A-1의 회전은 가속(2.35초)이 감속(1.40초)보다 길었습니다. A-2는 빠르게 오르고 길게 감속합니다.
- 무게 옮기기는 원래 움직임이 작은 구절이라, 준비·회복의 정지 비율이 50%에서 43%로 조금만 줄었습니다.

## 시각 검토 항목

개발 화면에서 ×1.5(시작값)와 ×1로 각각 보고, `C`로 A-1과 나란히 비교해 주세요. 시간은 A-2 전체 순서 기준입니다.

**속도와 연결감 (이번 수정)**
- [ ] ×1과 ×1.5 중 어느 쪽이 선의 변화량에 맞는가, 혹은 ×1.25·×2가 나은가
- [ ] 구절 경계(7.2초, 16.2초, 25.7→0초)에서 '동작 시범이 끝나고 다음 시범이 시작되는' 느낌이 사라졌는가
- [ ] 회복이 다음 준비로 넘어가는 흐름이 억지스럽지 않은가: 무게 옮기기 → 응축, 펼친 팔이 내려오며 감김 → 회전, 착지 → 왼발로 건너감
- [ ] 처음 들어왔을 때 2~3초 안에 무게 이동, 어깨선의 회전, 왼팔이 열리는 것이 보이는가
- [ ] 펼치기(9.3–10.2초)와 회전(18.3–19.8초)의 폭발과 긴 감속이 구분되는가

**전체**
- [ ] 선의 장식 없이 7개 구조선만으로 무게 이동과 동작의 계기가 보이는가
- [ ] 단순한 좌우 흔들림으로 읽히지 않는가(높낮이, 골반·어깨의 반대 기울기, 자유 다리의 반응)

**무게 옮기기**
- [ ] 오른발이 버티는 동안 발이 미끄러져 보이지 않는가(기준점 표시의 붉은 원 위치)
- [ ] 몸통 기울기가 골반보다 늦게 오는 것이 무게를 받아 내는 반응으로 보이는가

## 남은 한계

- 안무는 임시안이며, 좌우·크기·길이의 변주가 없는 고정 순서입니다.
- A-2는 순서(무게 옮기기 → 펼치기 → 방향 바꾸기)를 전제로 각 구절의 끝과 시작을 맞췄습니다. 구절 하나만 반복하면 그 구절의 끝이 자기 시작으로 이어지므로 경계의 흐름이 전체 순서보다 덜 자연스러울 수 있습니다.
- 감상 화면의 배속은 1로 두었습니다. 검토 후 정한 배속을 `CONFIG.playback.speed`에 반영하면 됩니다.
- 구조선은 관절을 잇는 곡선이며, 단계 B의 선 표현(몸을 가로지르는 곡선, 끊김, 밀도)은 아직 없습니다. 지금은 막대 인형에 가깝게 보일 수 있습니다.
- 발은 발목 점 하나로만 다루므로 발 앞꿈치·뒤꿈치의 구분이나 회전 중 발의 비틀림은 표현하지 않습니다.
- 말단 시간차는 이전 시점의 자세를 빌려오는 방식이라, 빠른 회전에서 팔꿈치·손끝이 제약에 걸려 각이 지는 순간이 있을 수 있습니다.
- 무게 중심은 골반·가슴·머리만으로 계산한 근사입니다.
- 화면 크기 변경 시 비례를 다시 계산하지만, 감상 환경(움직임 감소 설정, 터치, 탭 복귀 처리의 완성)은 단계 D의 범위입니다. 탭이 가려지면 프레임이 멈추고, 돌아왔을 때 공백 시간을 반영하지 않는 것까지만 되어 있습니다.
