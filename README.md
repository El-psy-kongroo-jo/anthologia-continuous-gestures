# anthologia-continuous-gestures

ANTHOLOGIA — CONTINUOUS GESTURES. 인간의 몸과 춤을 암시하는 선들이 실시간으로 움직이는 웹 기반 생성 작품입니다.
작품 설계와 단계별 범위는 [PROJECT_BRIEF.md](PROJECT_BRIEF.md)에 있습니다.

**현재 상태: 단계 B — 선의 표현 검증 중(Flow).** 단계 A의 안무 A-2와 보이지 않는 신체 구조는 그대로 두고,
기본 감상 화면의 표현을 뼈대 선에서 **Flow**(천처럼 흐르는 선들 사이에서 몸이 드러나는 표현)로 바꿨습니다.
단계 A의 뼈대 표현은 **Structure** 모드로 보존해 개발 화면에서 볼 수 있습니다.
형상 전환(단계 C), 포인터·음향·감상용 조작부·모드 선택 UI(단계 D), Trace 모드, 배포(단계 E)는 아직 구현하지 않았습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다.

```sh
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 시간·보간·신체 제약·Flow 기하 테스트
npm run build      # 타입 검사 + 프로덕션 빌드 (dist/)
npm run preview    # 빌드 결과 확인 (http://localhost:4173)
```

## 기본 감상 화면

`http://localhost:5173/`을 열면 바로 움직임이 시작됩니다. 화면에는 캔버스 하나만 있고 버튼이나 설명은 없습니다.
안무 A-2 전체 순서(무게 옮기기 7.2초 → 펼치기 9초 → 방향 바꾸기 9.5초, 25.7초 주기)를 Flow 기본 표현으로 보여 줍니다.
배속은 1입니다(`CONFIG.playback.speed`). 이전 화면(Structure)으로 돌아가려면 `CONFIG.viewing.mode`를 `'structure'`로 바꿉니다.

> Flow는 '펼침 → 방향 전환 → 멈춤' 구간을 기준으로 다듬었습니다. 무게 옮기기 구절과 응축 장면은 아직 따로 다듬지 않았습니다.

## 감상 모드(최종 구성)

최종 작품은 같은 안무를 세 감상 모드로 보여 줄 예정입니다. 세 모드는 같은 안무 시간과 같은 몸 상태를 공유하며,
모드는 그리기만 담당하고 상태를 갖지 않으므로 전환해도 동작이 초기화되지 않습니다.

| 모드 | 내용 | 현재 |
|---|---|---|
| Structure | 최소한의 선으로 몸과 안무를 드러냄(단계 A의 구조선 7개) | 구현됨, 개발 화면에서 선택 |
| Flow | 여러 선이 함께 흐르며 몸을 암시. **기본 감상 모드** | 기본 표현 1개 검증 중 |
| Trace | 지나간 움직임의 궤적과 시간의 층 | 아직 구현하지 않음 |

관객용 모드 선택 UI는 아직 없습니다(단계 D).

## Flow 표현

레퍼런스 이미지(가느다란 선들이 띠·면을 이루며 접히고 펼쳐지는 드로잉)를 선의 밀도·간격·접힘·곡률의 기준으로 삼았습니다.
외곽 형태를 복제하지 않습니다.

- **천처럼 흐르는 면.** 폭이 넓은 긴 면(스카프·자락) 세 장이 몸에 걸립니다.
  - 앞쪽 두 면: 들어 올린 팔 → 어깨 → 가슴을 가로질러 → 반대쪽 골반을 감고 → 뒤로 끌리는 끝. 두 면이 가슴 위에서 X로 엇갈려 매듭을 만듭니다.
  - 뒤쪽 면: 목 뒤에서 등을 타고 뒤로 넓게 흐르는 자락.
- **선은 면의 길이 방향 결**입니다. 사지마다 붙인 튜브나 몸의 외곽선이 아닙니다.
- **몸은 선들 사이에서 드러납니다.** 보이지 않는 몸의 부피(캡슐을 매끄럽게 이은 표면)에 면이 걸리고 밀려나서, 어깨·팔·가슴을 넘을 때 결이 휘고 촘촘해집니다. 면 사이로는 옆구리·다리·머리가 비치고, 보이지 않는 몸이 뒤의 결을 가려 빈 공간으로 드러납니다. 모든 부위가 항상 선명하지는 않습니다.
- **간격.** 면이 비틀리거나 몸의 곡면에서 돌아서면 결이 모이고(긴장), 펼쳐지면 벌어집니다(부피). 응축할수록 결과 나란한 주름이 깊어집니다.
- **관성.** 걸린 곳(어깨·팔·골반)은 몸을 빠르게 따르고, 자유로운 끝은 2차 감쇠계의 응답으로 따라옵니다. 몸이 멈추거나 방향을 바꾸면 끝자락은 이전 방향으로 조금 더 갔다가 돌아옵니다. 반복 파동이 아니라 실제 몸의 움직임에 대한 응답이며, 과거 몸 상태를 다시 계산해서 쓰므로 시간 탐색과 재현이 그대로 유지됩니다.
- **앞뒤와 가림.** 천을 작은 조각으로 나눠 먼 것부터 그리고, 각 조각은 배경색으로 뒤를 덮은 뒤 자기 결을 그립니다. 앞의 천이 뒤의 결을 가리고, 보이지 않는 몸도 뒤의 결을 가립니다. 접혀서 안쪽 면을 보이는 곳은 옅게 그립니다. 외곽선이나 채운 면은 그리지 않습니다.
- 선마다 따로 흔들리는 무작위는 없습니다. 아주 약한 공유 변형장만 자유로운 부분에 더합니다.

**세 설정.** 개발 화면에서 같은 동작·같은 시점을 비교할 수 있습니다.

| 설정 | 내용 | 상태 |
|---|---|---|
| Flow 1 · 몸이 읽힘 | 기본 표현에서 천이 몸에 더 붙고 덜 늘어짐 | 미조정(기본 표현의 수치만 바꾼 변형) |
| Flow 2 · 경계 | 몸과 추상의 경계. **기본 표현** | 검토 구간 기준으로 다듬는 중 |
| Flow 3 · 흐름 | 천이 더 늘어지고 넓게 흐르며 몸이 희미함 | 미조정(기본 표현의 수치만 바꾼 변형) |

## 개발용 검토 화면

주소에 `?dev`를 붙이면 열립니다(예: `http://localhost:5173/?dev`). 기본 감상 화면에서는 이 패널의 코드도 불러오지 않습니다.
개발 화면은 **검토 구간 '펼침 → 방향 전환 → 멈춤'**(A-2 전체 순서의 9.0~22.8초 반복), Flow 2, 배속 ×1.5로 시작합니다.

| 기능 | 조작 |
|---|---|
| 구절 선택 | 선택 상자, 또는 `0` 전체 순서 · `1` 무게 옮기기 · `2` 펼치기 · `3` 방향 바꾸기 · `4` 검토 구간 |
| 표현(감상 모드) | 선택 상자 또는 `M`: Structure ↔ Flow. 시간은 그대로 이어집니다 |
| Flow 설정 | 선택 상자 또는 `F`: 1 → 2 → 3 |
| 나란히 비교 | 선택 상자 또는 `C`: 없음 → Flow 1·2·3 → Structure·Flow → 안무 A-1·A-2 |
| 안무 버전 | 선택 상자 또는 `V`: A-2 현재 ↔ A-1 이전. 바꾸면 그 구절의 처음으로 돌아갑니다 |
| 정지 / 재생 | `Space` 또는 재생 버튼 |
| 시간 탐색 | 슬라이더, `←` `→` 1/30초, `Shift` + `←` `→` 1초 (이동하면 자동으로 정지) |
| 속도 | ×0.25 · ×0.5 · ×1 · ×1.25 · ×1.5 · ×2 (시작값 ×1.5) |
| 기준점 표시 | 체크 상자 또는 `R` (관절 점·하중 등 개발용 표시. 감상 모드와 별개로 위에 겹쳐 그림, 기본은 꺼짐) |

비교 화면의 칸들은 같은 시계와 같은 몸 상태를 씁니다. 표현·Flow 설정·비교 화면을 바꿔도 시간은 이어지고,
구절이나 안무 버전을 바꾸면 그 구절(검토 구간이면 구간)의 처음으로 돌아갑니다.

기준점 표시에서 보이는 것:

- 파란 점: 머리, 목, 가슴, 허리, 골반, 어깨, 팔꿈치, 손목, 고관절, 무릎, 발목
- 발밑의 붉은 원: 하중의 크기. 하중이 60% 이상이면 진하게 채워져 지지 발로 표시됩니다. 점선은 발목이 바닥에서 들린 높이입니다.
- 초록 점과 십자: 무게 중심과 그 바닥 투영
- 골반 아래의 짧은 파란 선: 골반이 향한 방향
- 패널 아래쪽: 안무 버전, 현재 구절·부분(준비/진행/유예/회복), 좌우 하중 비율. 다리가 닿지 않아 골반을 내려야 했으면 `골반 보정` 값이 함께 나타납니다(안무 데이터 오류의 신호).

특정 시점을 주소로 공유할 수 있습니다.

```
/?dev&t=3.0&paused                         검토 구간 시작에서 3초 뒤(펼친 팔)에서 정지
/?dev&compare=presets&t=10.2&paused        회전 중 Flow 1·2·3 나란히
/?dev&compare=modes                        Structure와 Flow 나란히
/?dev&phrase=all&mode=structure            단계 A의 화면(전체 순서, Structure)
/?dev&t=0.9&paused&panel=0                 패널 없이 선만 보기(캡처용)
```

`phrase`는 `scene | all | shift | open | turn`(기본 `scene`), `mode`는 `structure | flow`, `preset`은 `1 | 2 | 3`,
`compare`는 `presets | modes | versions`(값 없이 쓰면 `versions`), `v`는 `a1 | a2`,
`t`는 초(검토 구간에서는 구간 시작으로부터의 초), `paused`는 정지 상태로 시작, `speed`는 배속(목록의 값),
`refs=1`은 기준점 표시, `panel=0`은 패널 숨김입니다. 같은 안무·`phrase`·`t`·표현은 항상 같은 장면을 만듭니다.

### 움직임을 만드는 방식

- **작품 시간 → 자세는 순수 함수**입니다. 누적 시뮬레이션이 없으므로 시간 탐색, 정지 후 재생, 반복 재생이 항상 같은 장면을 만듭니다. Flow의 관성도 과거 시점의 몸을 다시 계산해 쓰므로 이 성질을 유지합니다.
- 각 구절은 28개 자세 채널(골반 위치·기울기, 가슴의 방향·기울기·굽힘, 머리, 팔 각도, 발 위치·들림)의 키프레임입니다. 키 사이는 단조 3차 보간으로 이어지고, 같은 값을 두 번 두면 정지, 극값에서는 감속이 됩니다. 준비 동작은 반대 방향의 작은 키로 직접 적었습니다.
- 모든 구절의 키는 채널마다 하나의 순환 곡선에 모입니다. A-1은 구절마다 t = 0에 휴식 자세 키를 두었고(`anchorRest`), A-2는 경계에 고정 자세가 없어 앞 구절의 마지막 키에서 다음 구절의 첫 키로 곧바로 이어집니다. 그래서 경계에서도 위치와 속도가 연속입니다.
- **골반과 가슴이 움직임을 이끕니다.** 머리, 위팔, 아래팔, 손끝은 각각 0.16 / 0.10 / 0.22 / 0.36초 이전 시점의 몸통·팔 자세에서 방향을 가져옵니다. 위치는 현재 부모 관절에서 이어지므로 길이는 그대로이고, 말단만 늦게 따라옵니다.
- **지지 발은 고정됩니다.** 발 위치는 안무 데이터에서 하중이 없을 때만 바뀌고, 다리는 역기구학으로 풀며, 다리가 닿지 않으면 발을 끌어오는 대신 골반을 낮춥니다.
- 하중은 무게 중심의 바닥 투영을 두 발 사이에 놓아 계산하고, 바닥에서 들린 발은 하중을 받지 않습니다.
- 회전 채널은 한 바퀴씩 누적되므로 방향 바꾸기 뒤에도 역회전 없이 다음 구절로 이어집니다.
- 정지 구간에서도 몸이 굳지 않도록 아주 작은 호흡이 있습니다. 호흡 주기는 순서 길이의 약수로 맞췄습니다.

### 시점

정면에서는 무릎 굽힘, 몸통의 말림·젖힘, 회전 준비가 화면 깊이 방향으로 사라졌습니다. 그래서 몸을 약 24° 돌린 3/4 시점에서 약간 내려다보도록 했습니다(`CONFIG.camera`). 이 시점 역시 검토할 가설입니다.

## 임시 안무

**기존 Anthologia 동작 자료는 아직 제공되지 않았습니다.** `src/motion/phrases-a2.ts`(현재)와 `phrases-a1.ts`(이전)의 자세와 타이밍은 PROJECT_BRIEF.md 4장의 구절 설명만을 근거로 만든 임시안이며, 기존 작품을 분석한 결과가 아닙니다. 자료가 제공되면 그 자료에 맞춰 다시 씁니다.

### A-2 (현재)

각 구절의 회복이 다음 구절의 준비가 됩니다. 시간은 구절 안의 초, 괄호는 전체 순서 안의 초(배속 1)입니다.

| 구절 | 준비 | 진행 | 유예 | 회복 → 다음 구절로 |
|---|---|---|---|---|
| 무게 옮기기 7.2초 (0–7.2) | 0–0.7 앞 구절에서 넘어온 왼발 버팀, 짧게 가라앉아 밀어냄 | 0.7–3.3 골반이 오른발 위로 빠르게 건너감. 가슴이 지지 발 쪽으로 돌고 자유로운 왼팔이 열렸다가 늦게 내려앉음. 몸통은 골반보다 늦게 반대로 기울어 균형 | 3.3–4.4 오른발 위에서 머묾 | 4.4–7.2 뒤꿈치를 내리고 가라앉으며 팔이 앞으로 모이기 시작 → 펼치기의 응축 |

## 남은 한계

- 안무는 임시안이며, 좌우·크기·길이의 변주가 없는 고정 순서입니다.
- A-2는 순서(무게 옮기기 → 펼치기 → 방향 바꾸기)를 전제로 각 구절의 끝과 시작을 맞췄습니다. 구절 하나만 반복하면 그 구절의 끝이 자기 시작으로 이어지므로 경계의 흐름이 전체 순서보다 덜 자연스러울 수 있습니다.
- 감상 화면의 배속은 1로 두었습니다. 검토 후 정한 배속을 `CONFIG.playback.speed`에 반영하면 됩니다.
- Flow는 기본 표현 하나를 '펼침 → 방향 전환 → 멈춤' 구간 기준으로 다듬는 중입니다. 무게 옮기기·응축 장면, Flow 1·3 변형은 아직 다듬지 않았습니다.
- Flow의 몸 부피는 캡슐을 이은 근사라서, 천이 머리나 팔을 지날 때 둥근 모양이 드러나는 순간이 있습니다.
- 가림은 천을 작은 조각 단위로 깊이 정렬하는 근사입니다. 거의 같은 깊이에서 겹치는 곳은 조각 경계를 따라 계단처럼 끊길 수 있습니다.
- Flow 세 칸 비교 화면은 프레임이 느립니다(개발용). 감상 화면은 한 칸입니다.
- 발은 발목 점 하나로만 다루므로 발 앞꿈치·뒤꿈치의 구분이나 회전 중 발의 비틀림은 표현하지 않습니다.
- 말단 시간차는 이전 시점의 자세를 빌려오는 방식이라, 빠른 회전에서 팔꿈치·손끝이 제약에 걸려 각이 지는 순간이 있을 수 있습니다.
- 무게 중심은 골반·가슴·머리만으로 계산한 근사입니다.
- 화면 크기 변경 시 비례를 다시 계산하지만, 감상 환경(움직임 감소 설정, 터치, 탭 복귀 처리의 완성)은 단계 D의 범위입니다. 탭이 가려지면 프레임이 멈추고, 돌아왔을 때 공백 시간을 반영하지 않는 것까지만 되어 있습니다.
